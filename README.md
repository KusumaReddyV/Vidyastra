# Vidyastra

Vidyastra is a learning and career development platform that helps students improve their skills, prepare for placements, and achieve their career goals.

## Features

* Resume Analyzer using NLP
* ATS Score Evaluation
* Skill Gap Detection
* Adaptive Quizzes
* Career Roadmaps
* Study Planner
* Mentor Assistant
* Performance Analytics

## Tech Stack

* Python
* Flask
* MongoDB
* spaCy
* Scikit-Learn
* HTML
* CSS
* JavaScript

## Installation

```bash
git clone https://github.com/KusumaReddyV/Vidyastra.git
cd Vidyastra

pip install -r requirements.txt
python -m spacy download en_core_web_sm

python wsgi.py
```

## Usage

Open in your browser:

```text
http://127.0.0.1:5000
```

## Goal

To provide students with a single platform for resume improvement, skill development, career guidance, and placement preparation.
